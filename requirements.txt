# Minimum versions rather than exact pins.
#
# This runs on Python 3.14, which is new enough that many packages do not yet
# publish wheels for older releases of themselves. Pinning pydantic to 2.11.9
# forced a downgrade to a version with no 3.14 wheel, so pip tried to compile
# pydantic-core from Rust source and failed.
#
# Pin exactly once there is a lockfile and a CI image with a fixed interpreter.
# Until then, >= lets pip pick something that actually has a wheel.

fastapi>=0.118
uvicorn[standard]>=0.37
pydantic>=2.13.5
pydantic-settings>=2.11

# File upload support for FastAPI. Without it, UploadFile endpoints fail at
# startup with an unhelpful error about python-multipart being missing.
python-multipart>=0.0.20

# PDF text extraction. Chosen over PdfPig (the .NET option) because it handles
# multi-column layouts and reading order markedly better, which is the whole
# reason extraction moved to Python.
pymupdf>=1.26
